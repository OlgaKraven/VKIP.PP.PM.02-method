# Практика «Настройка и обеспечение работоспособности программных и аппаратных средств устройств инфокоммуникационных систем»

Комплект методических материалов для производственной практики по ПМ.02 профессии **09.01.05 Оператор технической поддержки**.

## Состав

- `docs/index.md` — главная страница (тема, цель, задачи, структура практики, ссылки на учебные материалы и шаблон отчёта).
- `docs/subject_areas.md` — список 30 предметных областей (вариантов).
- `docs/theory/stage1-4.md` — 4 теоретические страницы:
    1. Инфокоммуникационные системы, ОС и виртуализация.
    2. Установка и настройка системного и прикладного ПО, СУБД.
    3. Диагностика, мониторинг и проверка работоспособности.
    4. Защита от несанкционированного доступа и базовое администрирование.
- `docs/practice/stage1-4.md` — 4 страницы практики:
    1. Развёртывание стенда и установка СУБД.
    2. Базовая настройка сети и защита от НСД.
    3. Мониторинг производительности и текущий контроль.
    4. Оформление отчёта по практике.
- `docs/assets/templates/Отчёт_по_практике_ПМ02.md` — Markdown-заготовка отчёта по практике (студент конвертирует в `.docx`/`.odt`).
- `student_infocomm_samples/` — учебные конфиги и скрипты: PostgreSQL, MySQL, сеть (`ufw`/`iptables`/`sysctl`), мониторинг (Prometheus/Bash), `.env`-примеры, аудит безопасности.

## Парный репозиторий со стендами

Готовый Ansible-стенд (6 ролей, 3 плейбука, 30 вариантов предметных областей):

```bash
git clone https://github.com/OlgaKraven/VKIP.PP.PM.02-projectWork.git
cd VKIP.PP.PM.02-projectWork
make deps
make up                       # развернуть весь стенд
make smoke                    # пост-проверка
make variant-init V=05        # активировать вариант (например, № 5 — колледж)
```

Подробнее — в [`README.md` репозитория стендов](https://github.com/OlgaKraven/VKIP.PP.PM.02-projectWork#readme).

Важно: парный Ansible-стенд рассчитан на Linux-среду (Ubuntu/Debian/Astra Linux). Windows-направление в методичке оформлено как отдельные команды PowerShell, практические блоки и чек-листы, а не как автоматизированный Ansible-стенд.
