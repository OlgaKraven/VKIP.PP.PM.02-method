# Производственная практика

**Настройка и обеспечение работоспособности программных и аппаратных средств устройств инфокоммуникационных систем**

## Цель практики

Сформировать практические навыки **установки, настройки и обеспечения работоспособности** системного и прикладного ПО, СУБД, сетевых сервисов и средств защиты от несанкционированного доступа в составе устройств инфокоммуникационной системы (ИКС), а также навык **текущего контроля и мониторинга** их производительности и защищённости.

## Задачи

1. Изучить состав и архитектуру инфокоммуникационных систем, роль системного ПО, СУБД, сетевых сервисов и средств защиты.
2. Освоить установку и базовую настройку системного и прикладного ПО (включая сетевое ПО и ПО защиты от НСД) согласно руководствам производителя.
3. Развернуть СУБД (PostgreSQL/MySQL/MS SQL Express) и выполнить первичную инициализацию, создать БД и пользователей с разграничением прав.
4. Выполнить базовую настройку сетевой инфраструктуры (IP-адресация, фильтрация трафика, виртуальная сеть) и проверить корректность работы устройств.
5. Задать базовые параметры ПО для учёта конфигураций, мониторинга производительности и защиты от НСД.
6. Применить методы статической и динамической конфигурации параметров ОС.
7. Выполнить текущий контроль и мониторинг производительности устройств и виртуальных вычислительных ресурсов.
8. Проверить уровень защищённости устройств и виртуальных ресурсов от несанкционированного доступа.
9. Выполнить задание по индивидуальному [варианту предметной области](subject_areas.md) (1 из 30).
10. Оформить отчёт по практике с выгрузкой конфигов, дампов БД, журналов и скриншотов.

## Структура практики

Практика построена в двух слоях, объединённых одним и тем же набором умений и навыков:

- **Общая часть** — единый для всех студентов комплекс заданий: развёртывание СУБД, базовая настройка ОС, диагностика ПК.
- **Индивидуальная часть** — задание по [одному из 30 вариантов предметной области](subject_areas.md): требования к ИКС подбираются под специфику отрасли (банк, поликлиника, склад, ритейл и т.д.).

| Этап | Тема |
|------|------|
| 1 | Инфокоммуникационные системы, ОС и виртуализация |
| 2 | Установка и настройка системного и прикладного ПО, СУБД |
| 3 | Диагностика, мониторинг и проверка работоспособности |
| 4 | Защита от несанкционированного доступа и базовое администрирование |

Каждому теоретическому этапу соответствует практический:

| Практический этап | Содержание |
|-------------------|------------|
| 1 | Развёртывание стенда и установка СУБД |
| 2 | Базовая настройка сети и защита от НСД (фильтрация, ACL, политики паролей) |
| 3 | Мониторинг производительности и текущий контроль (perfmon/resmon/top/htop, prometheus-node-exporter) |
| 4 | Оформление отчёта по практике |

## Парный репозиторий со стендами

Готовый Ansible-стенд для практики (6 ролей, 3 плейбука, 30 вариантов): [`OlgaKraven/VKIP.PP.PM.02-projectWork`](https://github.com/OlgaKraven/VKIP.PP.PM.02-projectWork).

```bash
git clone https://github.com/OlgaKraven/VKIP.PP.PM.02-projectWork.git
cd VKIP.PP.PM.02-projectWork
make deps                                  # установить Ansible-коллекции
make up                                    # развернуть весь стенд
make variant-init V=05                     # активировать вариант (5 — колледж)
make smoke                                 # пост-проверка
```

Стенд автоматически выполняет всё, что описано в [практических этапах](practice/stage1.md): развёртывание СУБД, настройку сети и НСД, запуск мониторинга. Студент проверяет результат, фиксирует артефакты в `report/` и оформляет отчёт по шаблону.

## Учебные материалы (учебная папка)

В репозитории методички в папке `student_infocomm_samples/` находятся готовые конфигурационные шаблоны и скрипты:

| Папка | Содержание |
|-------|------------|
| `postgres_setup/` | `init.sql`, `pg_hba.conf`, переменные окружения для PostgreSQL |
| `mysql_setup/` | `init.sql`, `my.cnf`, скрипты создания пользователей |
| `network_config/` | `ufw.rules`, `iptables.sh`, `sysctl.conf`, шаблон `netplan` |
| `monitoring/` | bash-скрипты сбора метрик, шаблон `prometheus.yml`, `node_exporter.service` |
| `security/` | политика паролей, аудит SUID, чек-лист Linux/Windows hardening |

Каждая подпапка содержит свой `README.md` с пояснениями.

- заключение и таблицу ссылок на репозитории (методичка + личный репозиторий со скриптами).
