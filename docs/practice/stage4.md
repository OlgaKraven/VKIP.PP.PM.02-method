# Этап 4. Оформление итоговых материалов практики

## Задание

На данном этапе необходимо:

1. Подготовить итоговые материалы практики в форме, установленной преподавателем.
2. Включить результаты этапов 1–3, конфигурационные файлы, скриншоты, дампы и сводные таблицы.
3. Оформить вариативную часть (по индивидуальной [предметной области](../subject_areas.md)).
4. Сформировать репозиторий с конфигами и скриптами и приложить ссылку.
5. Подготовиться к защите.

## Индивидуальная часть

Индивидуальная часть формируется образовательной организацией. Содержание определяется требованиями работодателя / спецификой стенда варианта.

Рекомендованная структура индивидуальной части практики:

1. **Описание предметной области** (см. [список вариантов](../subject_areas.md)) и её требований к ИКС.
2. **Состав стенда варианта** — какие сервисы дополнительно поднимаются (1С, Битрикс24, Moodle, iiko, СКУД, IP-телефония и т.д.).
3. **Расширенная настройка**:
    - SSO/AD/LDAP (если применимо);
    - резервное копирование по расписанию;
    - публикация веб-интерфейса по HTTPS;
    - VLAN / VPN до удалённого офиса.
4. **Долгосрочный мониторинг и алертинг**: триггеры в Zabbix / правила Alertmanager / уведомления в почту/Telegram.
5. **Аудит ИБ** по чек-листу варианта, сводная таблица рекомендаций.
6. **Описание выполненной работы** — отдельный раздел в итоговых материалах.

## Репозиторий студента

Создайте свой публичный/приватный репозиторий со всеми конфигами и скриптами:

```bash
mkdir VKIP.PP.PM.02-stand-42
cd VKIP.PP.PM.02-stand-42
git init
mkdir -p configs scripts dumps screenshots
# скопируйте сюда финальные конфиги, дампы, скрипты, скриншоты
git add .
git commit -m "init: stand for variant 42"
git remote add origin git@github.com:<user>/VKIP.PP.PM.02-stand-42.git
git push -u origin main
```

В отчёт — таблица ссылок:

| № | Артефакт | Ссылка |
|:--:|---------|--------|
| 1 | Методичка по практике | https://github.com/OlgaKraven/VKIP.PP.PM.02-method |
| 2 | Стенд студента | https://github.com/<user>/VKIP.PP.PM.02-stand-42 |
| 3 | Дамп БД | `dumps/corpdata_42.sql` |
| 4 | Скриншоты | папка `screenshots/` |

## Защита практики

К защите необходимо подготовить:

1. печатный или электронный экземпляр отчёта;
2. демонстрацию рабочего стенда (ВМ запущена, сервисы работают);
3. готовность ответить на вопросы по 4 этапам;
4. чек-лист самопроверки.
